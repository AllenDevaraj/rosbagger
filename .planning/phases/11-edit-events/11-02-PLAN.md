VERIFIED rosbags converter building blocks (RESEARCH Pattern 2 / Don't-Hand-Roll; importable in rosbags 0.11.2 — confirmed via inspect.signature):
```python
from rosbags.convert.converter import is_same_wireformat, generate_message_converter
is_same_wireformat(src_typestore, dst_typestore, src_msgtype, dst_msgtype) -> bool
generate_message_converter(
    src_typestore, dst_typestore, src_msgtype, dst_msgtype, cache: dict[str, object],
    *, src_is2: bool, dst_is2: bool,
) -> Callable[[bytes | memoryview], memoryview]
# generate_message_converter chooses, PER msgtype:
#   is_same_wireformat AND src_is2==dst_is2 → memoryview            (raw copy)
#   is_same_wireformat AND src is cdr        → src_ts.cdr_to_ros1    (byte-level)
#   is_same_wireformat AND src is ros1       → dst_ts.ros1_to_cdr    (byte-level)
#   else (field set differs, e.g. seq)       → migrate_bytes(...)    (deser→migrate→reser)
```
The destination typestore: the target ROS version's built-in store — `rosbags.typesys.get_typestore(Stores.ROS1_NOETIC)` for a `.bag` dst, `Stores.ROS2_HUMBLE` for a ROS2 dst (mirrors tools/make_fixtures.py). `dst_msgtype` is normally the same as the source msgtype (rosbags handles legacy renames internally via STATIC_MSGTYPE_RENAMES); for the fixture corpus (Twist/Imu/Image) the names are identical across ROS versions. `src_is2`/`dst_is2` follow the `is2 = suffix != '.bag'` rule (input is2 from the source bag's format, dst is2 from `make_writer`'s decision).

NOTE on Open Q1 (LOCKED here per RESEARCH recommendation, refined): `rosbags.convert.convert(...)` is a whole-bag function with 12 REQUIRED positional args (srcs, dst, dst_storage, dst_version, compress, compress_mode, default_typestore, typestore, exclude_topics, include_topics, exclude_msgtypes, include_msgtypes — verified) and owns its own reader+writer lifecycle; it does NOT do trim/downsample. Rather than maintain TWO code paths (a brittle 12-arg `convert()` call for `bagq convert` AND the replicated factory for `bagq edit`), UNIFY on the edit pipeline: `bagq convert` calls `edit_bag` with an empty/no-filter `EditOps` and a destination format that differs from the source — the SAME converter factory engages. This most directly satisfies D-10 ("bagq convert shares the edit pipeline") and avoids the brittle whole-function call. (If a future need for `convert.convert`'s built-in compression appears, it can be added then.)
