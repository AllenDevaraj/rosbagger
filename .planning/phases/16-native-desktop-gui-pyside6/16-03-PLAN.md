Threading (D-15, RESEARCH Pattern 3): QObject worker moved to a QThread, started via a signal,
  emitting result/failed/finished signals back to the UI thread. NEVER subclass QThread.
  Teardown: finished->thread.quit, finished->worker.deleteLater, thread.finished->thread.deleteLater;
  keep self._thread/self._worker refs; on close quit()+wait() any running thread (Pitfall 2).

Replay re-entrancy (Pitfall 7 / TUI WR-06): only issue Play/Step BETWEEN run segments; ignore a
  control with a teaching status while a drive worker runs (Pause is allowed). One exclusive drive
  thread at a time. record_topics has no in-process early-stop hook — Stop dismisses; the bounded
  duration finalizes the capture (TUI WR-03).
