<objective>
Fix the Rerun live mirror so it works **regardless of toggle order**. Today `open_viewer()` returns
the instant `rec.spawn()` is called — the viewer is still starting, so the first logged items (a large
**Image** first) are dropped into an unconnected stream; the sink swallows the error
(`logged['errors']`) and `_open_rerun` discards it. Result: "image doesn't play if you open Rerun then
press Play." This plan (1) **gates on viewer readiness** after spawn (bounded, off the UI thread),
(2) **anchors the `bag_time` timeline to bag start** (`t0_ns=items[0].t_ns`) so the timeline is
order-independent, and (3) **surfaces `logged['errors']`** on the status line.

Requirement **RR-FIX**: opening Rerun before OR after Play mirrors all topics (incl. Image); no silent
drops; the GUI never freezes while the viewer spawns.
</objective>
