<!-- Styling is token-driven: panels set objectNames; ALL color lives in theme/qss.py (17-01).
     NEVER add an inline setStyleSheet("color: #...") literal in a panel (D-03 anti-pattern). -->

From widgets/status.py (17-02):
  set_status(label, text, *, is_error=False) -> None

Theme contract (17-01 theme/qss.py): build_qss already styles QWidget / QTableView /
QHeaderView::section / QSplitter::handle and a #status_error objectName. To theme a panel-specific
widget, give it an objectName and EXTEND theme/qss.py with a selector for that objectName — do NOT
write inline QSS in the panel. theme/qss.py is the ONLY place QSS strings live (D-03).

Record/replay status today: both call self._status.setText(...) directly (record_panel.py + replay_panel.py
many sites). Replace those with set_status(self._status, ...) and mark is_error=True on the failure/teaching
paths so the accessible Alert fires on a real desktop (guarded no-op offscreen, D-09).
</interfaces>
