## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| uv venv ↔ ROS runtime | `record.py` must import ROS-free in the uv venv; every rclpy/rosbag2_py/rosidl_runtime_py import is inside a function body. |
| live ROS graph ↔ recorder | The recorder subscribes to a trusted local ROS graph (robot/sim the user owns) and writes a local bag file. Payloads are opaque CDR bytes (`raw=True`), never deserialized in Python. |
| output path (`-o`) ↔ filesystem | The output bag path is a local filesystem path supplied by the trusted local user; rely on rosbag2_py's own path handling. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-01 | Tampering | `record.py` ROS-import boundary | mitigate | All rclpy/rosbag2_py/rosidl imports lazy inside function bodies; verify task asserts the bare module import leaks no ROS in the uv venv (grep-gated + sys.modules assertion). |
| T-12-03 | Denial of Service | unbounded recording fills disk | accept (with control) | D-09 `--max-messages`/`--duration` bounded modes + SIGINT stop give the operator control; an unbounded run is the user's explicit choice (document it). Split-by-size is deferred (out of scope). Local trusted user. |
| T-12-04 | Tampering | malicious/huge serialized payload on a topic | mitigate | `raw=True` writes bytes verbatim without deserializing in Python (D-05) — no per-type parser to exploit; the payload is opaque CDR handed straight to the writer. |
| T-12-05 | Denial of Service | recording finalize on crash/Ctrl-C | mitigate | `writer.close()` in a `finally` finalizes the bag on every exit path so a partial bag still re-opens (SC3); Task 2 proves close-on-error. |

No HIGH threats: local CLI subscribing to a trusted local ROS graph and writing a local file; no network, auth, session, crypto, or injection surface.
