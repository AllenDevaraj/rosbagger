## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI args -> replay() | bag path + --rate/--start/--topics (trusted local data; --rate validated >0 in the scheduler) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-06 | Tampering | replaying a malformed CDR payload | accept | deserialize_message is the same parser every ROS node uses; the bag is the user's own trusted data; a bad payload fails locally with no privilege boundary crossed. |
| T-13-07 | Denial of Service | unbounded --loop floods the graph | mitigate | --duration/--max-messages bound the run + Ctrl-C; the CLI help documents that --loop runs until stopped (mirrors Phase-12 bounded discipline). |
| T-13-08 | Information Disclosure | rclpy leaking into the offline import graph | mitigate | all rclpy/rosidl imports are inside replay.py function bodies behind _require_ros; test_import_replay_does_not_pull_ros (fresh PYTHONPATH='' subprocess) regression-locks it. |
| T-13-09 | Elevation of Privilege | capability gate bypass | mitigate | replay() goes through _require_ros() (lazy rclpy import -> teaching RosNotAvailableError when absent), so it is impossible to reach the publish path without a sourced ROS env. |
