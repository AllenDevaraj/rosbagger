  <behavior>
    - play/pause: play() sets PLAYING; pause() sets PAUSED and holds the cursor (a later run() resumes from the same index).
    - step: step() then run() publishes EXACTLY one item (the cursor advances by 1) and the state returns to PAUSED; a second step()+run() publishes the next one.
    - seek: seek(t_offset_ns) sets the cursor to the first index i with items[i].t_ns >= items[0].t_ns + t_offset_ns; seek past the end lands cursor == len(items) (run() then reaches DONE without publishing); seeked-over items are NEVER passed to the sink.
    - rate: with an injected recording sleep, run() over items spaced Δt_ns sleeps Δt_ns/1e9/rate seconds between consecutive publishes; set_rate(2.0) halves the slept value; set_rate(0) and set_rate(-1) raise ValueError; the first item incurs no pre-sleep.
    - loop: loop=True restarts cursor=0 at end-of-stream (run() keeps going / re-publishes from the top); loop=False sets DONE at end and run() stops.
    - bounded stop: max_messages=N halts after exactly N sink calls (use `is not None`, not truthiness — max_messages=0 means zero, not unbounded, WR-01); duration=D (seconds) halts when the INJECTED clock has advanced >= D since run() start (monotonic, WR-02); both None = run to natural end/loop.
    - clock/sink injection: clock, sleep, and sink are all injectable so the whole suite runs instantly with a fake clock and a list.append sink — no real sleeping, no ROS.
  </behavior>
