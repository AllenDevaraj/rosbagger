<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user SQL → alias rewrite (T-05-04 lineage) | The user's SQL is the INTENDED trusted interface of a local single-user CLI (Phase 5 T-05-04). The alias rewrite must keep that boundary: it rewrites INSIDE the sqlglot AST and regenerates SQL — it interpolates no raw string itself. |
| bag-derived names → alias target (T-03-06 lineage) | The dotted alias *targets* are author-controlled constants in `ALIAS_PACK` (not user input; D-05 not user-extensible). They are emitted as quoted identifiers via `exp.column(..., quoted=True)` — the same identifier-quoting boundary as Phase 3 T-03-06. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-01 | Tampering | alias-target string interpolation | mitigate | Build the replacement node ONLY via `exp.column(target, quoted=True)` inside `tree.transform` — NEVER an f-string/`+`/`%`. sqlglot escapes embedded quotes (T-03-06 lesson, VERIFIED). The acceptance criteria grep-gate this. |
| T-10-02 | Tampering | `ALIAS_PACK` as an injection vector | accept | The pack is a hard-coded dict of author-chosen dotted names (D-05 — not user-extensible in v1); no untrusted data flows into it. Existence-gating (D-04) further constrains what it can ever emit. |
| T-10-03 | Information disclosure (mild) | existence-gate bypass exposing a wrong column | mitigate | Gate strictly on `target in schema_names`; a miss leaves the ORIGINAL token, which surfaces the normal `UnknownColumnError` teaching path (CLI-03) in the orchestrator — never a silent wrong-column read. |
| T-10-SC | Tampering | npm/pip/cargo installs | accept | Zero new packages (10-RESEARCH § Package Legitimacy Audit — sqlglot/pyarrow/rosbags already locked). `alias.py` imports only `sqlglot.exp`. No install task, so no `[ASSUMED]`/`[SUS]` legitimacy checkpoint applies. |

**Residual risk after mitigations:** No HIGH-severity threats. The alias rewrite sits entirely upstream of `backend.execute`, stays inside the sqlglot AST, and emits only quoted identifiers from an author-controlled constant pack — introducing NO new injection surface beyond the already-vetted T-05-04 / T-03-06 boundary. The single accepted residual (the constant pack) carries no untrusted data.
</threat_model>
