<objective>
Define the typed, swappable bag-reader seam: an abstract `BagReader` base class (the contract a future `rosbag2_py` backend can also satisfy) plus the frozen `Message` record dataclass that every reader yields. This is the interface-first contract that plan 02-02 (`RosbagsReader`) implements against and plan 02-03 tests against.

Purpose: Establish the swappable backend seam (design spec §4.1, §3.3 principle 6) so the concrete `rosbags` implementation is one of potentially several. The `base.py` module deliberately imports NO `rosbags` and NO ROS, so the abstract seam stays importable without the heavy backend and the offline invariant is preserved.

Output: `reader/base.py` (BagReader ABC + Message dataclass) and a `reader/__init__.py` that re-exports them as the subpackage's public API.
</objective>

Message record (02-RESEARCH.md Code Examples §2 — the verified field set/order):
  topic: str            # connection.topic
  t: int                # log/receive time in nanoseconds (Phase 3 maps -> TIMESTAMP_NS)
  t_ns: int             # same value, explicit ns (Phase 3 -> BIGINT column)
  stamp: int | None     # header.stamp in ns, or None when the msg has no header
  msgtype: str          # connection.msgtype
  msg: object           # the deserialized rosbags message object (the "fields")

BagReader abstract surface (02-RESEARCH.md Pattern 1 — mirrors rosbags.highlevel.AnyReader's own open/close/__enter__/__exit__):
  @abstractmethod open(self) -> None
  @abstractmethod close(self) -> None
  @abstractmethod read(self) -> Iterator[Message]      # lazy generator, time-ordered across all opened bags
  @property @abstractmethod topics(self) -> Mapping[str, object]      # topic-name -> TopicInfo, metadata WITHOUT full deserialization (feeds Phase 4 Inspect)
  @property @abstractmethod connections(self) -> Sequence[object]     # per-connection metadata WITHOUT full deserialization
  __enter__(self) -> BagReader     # concrete, shared: calls self.open(); returns self
  __exit__(self, exc_type, exc, tb) -> bool   # concrete, shared: calls self.close(); returns False
</interfaces>
