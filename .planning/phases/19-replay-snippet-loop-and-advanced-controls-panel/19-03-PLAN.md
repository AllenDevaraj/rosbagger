<objective>
Wire the desktop Replay panel to expose the snippet-loop region as a usable control: a **collapsible advanced-controls sub-panel** inside the Replay tab ("the tab on the side" the user asked for) holding a "Loop region" toggle + "Set In"/"Set Out" buttons that snap to the live playhead, wired to BOTH the 19-02 Scrubber handles and the 19-01 scheduler region — and the region survives pause/seek/play. The panel stays a THIN face — zero analysis/bag/SQL/ROS logic added; every `rosbagger_replay` import stays inside method bodies; `build_publish_sink` untouched; Phase-18 live scrubbing (playhead poll, drag-while-playing seek, live rate/loop) preserved.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| UI thread ↔ Replayer region (now thread-safe) | The panel calls set_loop_region/clear_loop_region from the UI thread while run() reads the bounds on the worker — safe ONLY because 19-01 made the region setters lock-guarded + wake (this plan depends on 19-01) |
| region state durability ↔ transport rebuild | A region set before a pause/seek/play that rebuilds the transport would be lost unless re-applied — the panel owns the durable fraction state |
| desktop offline import graph ↔ ROS/Qt | replay_panel.py top level must stay PySide6+stdlib+local; the new region wiring keeps every rosbagger_replay import lazy inside methods |
