# Phase 18 Plan 01: Scheduler Thread-Safety (Pure)

**Phase:** 18 — Replay live scrubbing and thread-safe transport
**Plan:** 01 of 2
**Subsystem:** rosbagger-replay (pure `Replayer` scheduler)
**Requirements:** REP-02 -> ROADMAP Phase 18 SC1, SC4
**Depends on:** Phase 13. Wave 1 (18-02 depends on this).

---

## Objective

Make the pure `Replayer` safe to **control from another thread while `run()` executes**, so the desktop (18-02) can seek / set_rate / toggle loop / pause mid-playback without a data race — while preserving the existing **synchronous** control semantics (a `seek()` issued when not running still updates `cursor` immediately) and EVERY documented transport invariant. Mechanism: a `threading.Lock` guarding the small critical sections + a `threading.Event` making the inter-message pacing wait **interruptible** so a mid-gap control takes effect promptly. The scheduler stays **stdlib-only** (`threading` is the only addition; no ROS, no Qt).

---

## Acceptance Criteria

(AC# trace to ROADMAP Phase 18 Success Criteria.)

1. **AC1 (->SC1) race-free mid-run control.** With `run()` on a worker thread, a `seek(target)` from another thread lands the next published item at/after the target and advances the cursor from there (no lost update); a mid-run `set_rate` and `pause` also take effect. Proven by a deterministic threaded unit test.
2. **AC2 (->SC1) synchronous semantics preserved.** When `run()` is NOT executing, `seek/set_rate/pause/play/step` and the `loop` setting behave exactly as before (`seek()` then read `cursor` reflects the jump immediately). All pre-existing Phase-13 scheduler tests pass unchanged.
3. **AC3 (->SC1) responsiveness.** A control issued during a long inter-message gap interrupts the pacing wait instead of blocking until the gap elapses.
4. **AC4 (->SC4) invariants + purity.** W3 (seek the only position-setter), W4 (bound on final item -> DONE wins over loop), WR-01/WR-02 (`is not None` guards + zero/neg special-case), Pitfall 6 (seek-past-end -> clean DONE), D-08 pacing, step=one-then-pause all preserved. `scheduler.py` imports only stdlib (incl. `threading`). `import rosbagger_replay` ROS-free; `tests/test_offline_guard.py` green.

## Risks / Threat model
- **T-18-01-A lost-update race** (the core bug) -> cursor-unchanged advance guard + lock around mutations.
- **T-18-01-B deadlock/UI freeze** -> never hold the lock across sink()/sleep(); lock guards O(1) work only.
- **T-18-01-C broken injection seam** -> keep sleep/clock injectable; only the default sleep becomes interruptible (a test asserts an injected recording sleep is still honored).
- **T-18-01-D invariant drift (W4/WR-01/Pitfall6)** -> full pre-existing scheduler suite as a regression gate.
- **T-18-01-E test non-determinism** -> controllable barrier/Event in the injected sleep (no time.sleep races).
