<objective>
Make the pure `Replayer` safe to control from another thread WHILE `run()` executes, so the desktop (18-02) can seek / set_rate / toggle loop / pause mid-playback with NO data race — while preserving the existing synchronous control semantics (a `seek()` issued when not running still updates `cursor` immediately) and EVERY documented transport invariant.

Mechanism (RESEARCH §3a, the chosen design — lock + interruptible wait + advance guard, NOT a command queue): a `threading.Lock` guarding only the small critical sections plus a `threading.Event` that makes the inter-message pacing wait interruptible so a mid-gap control takes effect promptly.

Purpose: This is the FOUNDATION of v0.5 (CONTEXT locked decision: FULL live scrub). 18-02 wires the desktop on top; this plan proves SC1 (race-free mid-run control) and SC4 (purity + invariants) at the pure-scheduler tier.
Output: a thread-safe `scheduler.py` (stdlib-only; `threading` is the only addition — no ROS, no Qt) and a deterministic threaded race test in `tests/test_replay_unit.py`.
</objective>

| UI/worker thread ↔ Replayer state | The desktop (18-02) mutates `_cursor`/`_state`/`_rate`/`_loop` from the UI thread while `run()` reads/advances them on the worker thread — the data-race boundary CR-02 identified |
| injection seam ↔ default behavior | The `sleep`/`clock` injection seam (tests inject deterministic stand-ins) must survive making the DEFAULT sleep interruptible |
| rosbagger_replay ↔ ROS/Qt | A stray top-level ROS/Qt import would breach the offline/Qt-free invariant; `threading` is stdlib and allowed |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-01-A | Tampering | `_cursor` read-modify-write in run() vs concurrent seek() | mitigate | cursor-unchanged advance guard (`if self._cursor == cur: self._cursor = cur + 1`) + all mutations under `self._lock` — proven by the threaded lost-update test |
| T-18-01-B | Denial of Service | lock held across sink()/sleep() -> UI freeze/deadlock | mitigate | lock guards O(1) reads/transitions ONLY; explicitly released before every `self._sink(...)` / `self._sleep(...)` |
| T-18-01-C | Tampering | injection seam broken by interruptible default | mitigate | keep `sleep`/`clock` injectable; only the DEFAULT sleep becomes `_interruptible_sleep`; a test asserts an injected recording sleep is honored verbatim |
