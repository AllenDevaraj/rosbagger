Wire the desktop Replay panel to use the now-thread-safe `Replayer` (18-01) for FULL live scrubbing (CONTEXT locked decision): a live-tracking playhead that advances during playback, drag-while-playing seek with no "Pause before seeking" rejection, rate/loop changeable mid-play, and an honest backward-drag status ("Seeking to N% — resuming forward.").

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| UI thread ↔ Replayer (now thread-safe) | The panel mutates the Replayer (seek/set_rate/loop/pause) from the UI thread while run() executes on the worker — safe ONLY because 18-01 made the Replayer thread-safe (this plan depends on 18-01) |
| QTimer lifecycle ↔ panel/thread teardown | A live-playhead QTimer left running after the drive finishes or the panel closes would fire on a torn-down transport |
| desktop offline import graph ↔ ROS/Qt | replay_panel.py top level must stay PySide6+stdlib+local only; ROS imports stay lazy inside methods |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-18-02-A | Tampering | UI-thread seek/rate/loop vs run() on the worker | mitigate | depends on 18-01's thread-safe Replayer; the panel just removes the now-unnecessary guards (the race is handled in the scheduler) |
| T-18-02-B | Denial of Service | orphaned QTimer firing after drive/panel teardown | mitigate | timer stopped in BOTH _on_drive_finished AND closeEvent |
| T-18-02-C | Information Disclosure | backward drag implying reverse playback | mitigate | status says "Seeking to N% — resuming forward." — never claims a rewind (CONTEXT hard truth) |
| T-18-02-D | Tampering | set_position feedback loop re-emitting seeked | mitigate | rely on the Scrubber's existing _suppress_emit guard (known-correct fact); no new suppression |
| T-18-02-E | Elevation/Isolation | a stray top-level ROS/Qt import in replay_panel.py | mitigate | tests/test_offline_guard.py stays green; ROS imports stay lazy inside methods |
| T-18-02-SC | Tampering | npm/pip/cargo installs | accept | ZERO new packages (QTimer is PySide6, already a dep); nothing to slopcheck |
