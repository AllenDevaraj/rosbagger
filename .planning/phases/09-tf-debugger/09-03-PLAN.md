<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| shell user → bagq tf | A user runs `bagq tf BAG` on a possibly-missing or non-TF bag path. The CLI must fail cleanly (clean message + Exit(1), no traceback), never crash with a stack dump. |
| bag bytes → CLI render | The rendered values originate from the (Plan 02) analyzer, which only handles string frame-ids + int timestamps; the CLI formats them. No untrusted numeric payload reaches the renderer. |
| bag path / deserialization | Path existence and decoding are the v1 reader's responsibility (FileNotFoundError is caught by teaching_errors; other reader errors propagate per the established CLI contract). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-08 | Information disclosure | bagq tf on a missing/non-TF bag | mitigate | teaching_errors catches FileNotFoundError (missing path) and NoTransformsError (no TF topics) → one red stderr line + Exit(1), NO traceback (no internal paths/stack leaked). Asserted by the CLI no-TF test (isinstance SystemExit, raw error did not escape). |
| T-09-09 | Tampering | render path on edge values | mitigate | _render_tf_report formats only strings (frame ids) and ints (ns) via _human_dur; "—" guards every None field (static/single-sample edges). No eval/format-injection surface; an empty gaps list prints a "no gaps detected" line, not a crash. |
| T-09-10 | Denial of Service | --format json over a large report | accept | JSON is `dataclasses.asdict` over a bounded report (one entry per edge/gap); the analyzer already bounded the stream. Local single-pass tool over the operator's own bag — acceptable, low-severity. |
| T-09-SC | Tampering | npm/pip/cargo installs | accept | Zero new packages (RESEARCH §Package Legitimacy Audit). cli.py adds only stdlib `json`/`dataclasses` + existing typer/rich; tests add only pytest (already a dev dep). No install task; no addopts/uv.lock edit (Decision 1). |

**Residual risk after mitigations:** No HIGH-severity threats. The only new attack surface is the CLI command, whose failure modes (missing path, no-TF bag, malformed report) all resolve to a clean Exit(1) or a guarded "—"/"no gaps" render. Bag I/O remains the vetted reader's boundary.
</threat_model>
