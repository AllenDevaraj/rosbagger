- `_T0_NS = 1_000_000_000`, `_DT_NS = 100_000_000` — deterministic time base.

  then `writer.write(conn, t_ns, serialize(msg, msgtype))`.

- ROS 2: `with Ros2Writer(path, version=9, storage_plugin=StoragePlugin.{SQLITE3,MCAP}) as writer:`
  + `ts.serialize_cdr`; typestore `get_typestore(Stores.ROS2_HUMBLE)`.
- `write_def_less_bag(...)` shows the EXACT `ts.register(get_types_from_msg(<defs>, <msgtype>))`
  pattern this plan reuses for the ROS 1 TFMessage registration.
- Top-level imports already present: `from rosbags.typesys import Stores, get_types_from_msg, get_typestore`,
  `from rosbags.rosbag1 import Writer as Ros1Writer`, `from rosbags.rosbag2 import StoragePlugin, Writer as Ros2Writer`, `numpy as np`.

VERIFIED domain facts (RESEARCH §"TF / tf2 Message Model", verified against the live rosbags typestore):
- `/tf` and `/tf_static` are BOTH `tf2_msgs/msg/TFMessage`.
- `tf2_msgs/msg/TFMessage` has ONE field: `transforms` (a `geometry_msgs/msg/TransformStamped[]`). No top-level header.
- `geometry_msgs/msg/TransformStamped` fields: `header` (std_msgs/msg/Header — `header.frame_id` is the PARENT),
  `child_frame_id` (string, the CHILD), `transform` (`geometry_msgs/msg/Transform`).
- `geometry_msgs/msg/Transform` fields: `translation` (`geometry_msgs/msg/Vector3` x,y,z),
  `rotation` (`geometry_msgs/msg/Quaternion` x,y,z,w). A valid rotation is `(0,0,0,1)`.
- VERIFIED ROS 1 registration (rosbags 0.11.x, round-trips via serialize_ros1/deserialize_ros1):
  `ts.register(get_types_from_msg("geometry_msgs/TransformStamped[] transforms\n", "tf2_msgs/msg/TFMessage"))`.
  ROS 2 (`Stores.ROS2_HUMBLE`) ships TFMessage already — NO registration needed.
