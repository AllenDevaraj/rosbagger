```python
@dataclass(frozen=True, slots=True)
class Message:
    topic: str          # e.g. "/tf"            (connection.topic)
    t: int              # log/receive time, ns
    t_ns: int           # same ns value, explicit  ← THE TF timeline clock (Decision 3)
    stamp: int | None   # None for /tf (TFMessage has NO top-level header) — do NOT use as clock
    msgtype: str        # e.g. "tf2_msgs/msg/TFMessage"
    msg: object         # the DESERIALIZED TFMessage

class BagReader(abc.ABC):
    def read(self, *, topics: set[str] | None = None) -> Iterator[Message]: ...
    @property
    def message_count(self) -> int: ...
    @property
    def start_time(self) -> int: ...        # ns
    @property
    def end_time(self) -> int: ...          # ns
    @property
    def topics(self) -> Mapping[str, object]: ...   # name -> TopicInfo; .keys() are the topic names
```

  `read(topics=set())` / an unknown topic -> EMPTY stream (RESEARCH §Reuse Map — VERIFIED).
- A `TFMessage` has one field `transforms`; each item is a `TransformStamped` with

The canonical stream-walk (RESEARCH §"Pattern 1", mirrors bagq info's reader usage):
```python
for m in reader.read(topics={"/tf", "/tf_static"}):
    is_static = m.topic == "/tf_static"          # tag by TOPIC NAME (Decision 4), not msgtype
    for tfs in m.msg.transforms:
        key = (tfs.header.frame_id, tfs.child_frame_id)   # (parent, child) — Decision; keep series distinct
        edges.setdefault(key, []).append(m.t_ns)          # m.t_ns is the clock (Decision 3)
        if is_static:
            static.add(key)
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| bag bytes → TF walk | A possibly-adversarial/malformed bag's deserialized `/tf` payloads reach `collect_tf_report` (empty `transforms`, NaN/inf in translation/rotation, pathologically long `frame_id`/`child_frame_id`, self-referential parent==child, enormous transform counts, backwards/duplicate timestamps). The TF analyzer must not crash, divide by zero, or grow memory unboundedly on hostile input. |
| bag path / deserialization | Path handling and CDR/ROS1 decoding are the v1 reader's (`RosbagsReader`) responsibility — out of scope here (this module takes an already-open reader). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-03 | Denial of Service | gap math on backwards/duplicate timestamps | mitigate | Drop deltas `<= 0` before `statistics.median`; guard `expected <= 0` (skip gap math, record informationally) — no ZeroDivision, no negative-rate garbage (Decision 6 zero-duration/clock-skew case). |
| T-09-04 | Denial of Service | single-/zero-sample edge | mitigate | `len(times) < 2` short-circuits to no-gap informational `EdgeReport` — no median over an empty `diffs` list (IndexError/StatisticsError avoided). |
| T-09-05 | Tampering | NaN/inf in translation/rotation; empty `transforms` list | mitigate | The analyzer keys edges on `frame_id`/`child_frame_id` (strings) and times on `m.t_ns` (int log time) ONLY; it never reads `transform.translation`/`.rotation` numerics, so NaN/inf cannot enter the gap math. An empty `transforms` list contributes no edges (the inner loop simply doesn't execute). |
| T-09-06 | Denial of Service | enormous transform counts / unbounded per-edge series memory | accept | Per-edge time lists grow O(total /tf transforms) — inherent to streaming a stream once (the reader already bounds I/O; we store only int timestamps + (str,str) keys, not message bodies). For an offline, user-invoked, single-pass local analyzer over the user's OWN bag this is acceptable; a future cap is a non-blocking enhancement. No untrusted remote input. |
| T-09-07 | Information disclosure / Spoofing | self-referential edge (parent==child) or multi-parent-for-one-child | mitigate | Keying by `(parent, child)` keeps a `parent==child` edge as its own distinct series (not silently merged) and keeps a child's two parents as two distinct series (RESEARCH multi-parent edge case) — surfaced as distinct rows rather than corrupting another edge's stats. |
| T-09-SC | Tampering | npm/pip/cargo installs | accept | Zero new packages (RESEARCH §Package Legitimacy Audit). `tf.py` imports only stdlib (`dataclasses`, `statistics`); `errors.py` only `difflib`. No install task. |

**Residual risk after mitigations:** No HIGH-severity threats. This is an offline, read-only analyzer that touches only string frame-ids and integer log-times; the numeric-payload and resource-division hazards are guarded, and bag I/O is the (already-vetted) reader's boundary. T-09-06 (unbounded series on a hostile bag) is the only accepted residual and is low-severity for a local single-pass tool over the operator's own bag.
