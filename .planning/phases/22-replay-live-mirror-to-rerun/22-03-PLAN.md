<objective>
Wire the live mirror into the desktop Replay tab: a checkable **Open in Rerun** button at the end
of the control bar that, while on, tees every played message into Rerun via the 22-02
`build_rerun_sink`. The tee is **dynamic** — `_ensure_transport` builds the `Replayer` on a
composed sink that reads `self._rerun_sink` live — so toggling needs no transport rebuild and
`build_publish_sink` / the `260529-k6m` publish path stay byte-for-byte untouched. ROS-gated +
`rerun_available()`-gated, with **install-on-click** for `rerun-sdk` (in a kept-ref worker so the
GUI never blocks on pip — honoring the GC discipline this milestone just fixed). The mirror is
transport-independent: it survives rate-change rebuilds and is torn down only on toggle-off or
panel close.

Requirement **RR-3**: the toggle live-mirrors Play into Rerun additively (RViz unaffected),
gated + install-on-click, with the mirror proven end-to-end by a live `.rrd` desktop test.
</objective>

In _ensure_transport, replace the bare Replayer construction with a dynamic tee:
```python
sink, self._published = build_publish_sink(self._node, publish_clock=..., static_topics=...)
self._sink = sink
def _drive_sink(item):
    sink(item)                       # → ROS graph (unchanged)
    rsink = self._rerun_sink         # read LIVE (toggle needs no rebuild)
    if rsink is not None:
        rsink(item)                  # → Rerun
self._replayer = Replayer(items, _drive_sink, rate=rate, loop=self._loop_checkbox.isChecked())
```

Handlers (lazy `import rosbagger_rerun` inside _toggle_rerun):
```python
def _toggle_rerun(self, checked: bool) -> None:
    if not checked:
        self._close_rerun(); return
    if not self._ros_available():
        set_status(self._status, "Source ROS 2 to mirror replay to Rerun.", is_error=True)
        self._rerun_button.setChecked(False); return
    import rosbagger_rerun
    if not rosbagger_rerun.rerun_available():
        self._install_rerun(); return       # install-on-click, then _open_rerun
    self._open_rerun()

def _open_rerun(self) -> None:
    import rosbagger_rerun
    try:
        rec = rosbagger_rerun.open_viewer()                 # module attr → monkeypatchable
        self._rerun_sink, _ = rosbagger_rerun.build_rerun_sink(rec)
        self._rerun_rec = rec
        set_status(self._status, "Mirroring replay to Rerun…")
    except Exception as exc:  # noqa: BLE001 - teach, don't crash
        set_status(self._status, f"Rerun open failed: {exc}", is_error=True)
        self._rerun_button.setChecked(False)

def _close_rerun(self) -> None:
    self._rerun_sink = None
    rec = self._rerun_rec
    self._rerun_rec = None
    if rec is not None:
        with contextlib.suppress(Exception):
            rec.flush(blocking=True)     # best-effort; viewer window persists for inspection
```
