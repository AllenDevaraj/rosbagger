# Quick Task 260609-5yl — Plan

## Goal

Collapse "fetch new updates" to **one command** for every consumer (plain clone,
git submodule, ROS or not): `./update.sh`. No separate `git pull` /
`git submodule update`, and it leaves them ready to `colcon build` + `ros2 launch`
again.

## Why `--reinstall` is needed (correctness)

Re-running `./install.sh` when the package version is unchanged makes pip report
"already satisfied" and **skip the new code** — so riding `main` between version
bumps would silently not update. `update.sh` must force-reinstall the local
packages.

## Tasks

### Task 1 — `install.sh --reinstall`
- **File:** `install.sh`
- **Action:** Add a `--reinstall` flag (`reinstall=0`; arg-loop case; usage line).
  After the normal install pass, if set, run a SECOND pip pass over the local path
  `specs` with `--no-deps --force-reinstall` (and `--no-build-isolation` in `--user`
  mode) so our packages rebuild+reinstall at the same version. Applies to both venv
  and `--user` modes. Deps are untouched (first pass handled them).
- **Verify:** `bash -n`; `./install.sh --desktop --user --reinstall` force-reinstalls
  the 6 local pkgs and `rosbagger --help` exits 0; `--help` lists `--reinstall`.
- **Done:** `--reinstall` forces local-pkg reinstall without re-resolving deps.

### Task 2 — `update.sh`
- **File:** `update.sh` (new, mode 0755)
- **Action:** One-command updater run from the rosbagger checkout. Steps:
  1. Parse own flags `--no-build`, `--force`; everything else is forwarded to
     `install.sh` (default forward = `--desktop --user`).
  2. Refuse on a dirty tree unless `--force` (then `git stash -u`).
  3. `git fetch origin`; resolve default branch (origin/HEAD → fallback `main`);
     attach to it (create tracking branch if needed) and `git merge --ff-only` to
     origin's tip — handles a submodule's detached HEAD, so no separate
     `git submodule update` is required.
  4. Run `./install.sh <forwarded flags> --reinstall`.
  5. If the checkout sits at `<ws>/src/rosbagger` (parent dir name is `src`):
     when `ROS_DISTRO` is set, `cd <ws> && colcon build --symlink-install
     --packages-select rosbagger_ros`; otherwise print that exact command. Skip on
     `--no-build` or when not in a workspace.
  6. If `.git` is a FILE (submodule) and HEAD moved, print the
     `git add <path> && git commit` pointer-bump reminder.
- **Verify:** `bash -n`; running `./update.sh --no-build` from the repo is a safe
  no-op fetch (local already ≥ origin → ff no-op) + reinstall, exits 0, skips colcon
  (parent is `Desktop`, not `src`).
- **Done:** One command fetches latest + reinstalls; ROS users can then rebuild +
  launch.

### Task 3 — Document the updater
