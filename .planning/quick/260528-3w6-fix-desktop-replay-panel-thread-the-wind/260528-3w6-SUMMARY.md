# Phase quick-260528-3w6: Replay Typestore Passthrough Summary

Pressing **Play** in the desktop replay tab on a real ROS 2 `rosbag2` sqlite3 recording
failed with `AnyReaderError: Bag contains no type definitions. Instantiate AnyReader with
a default_typestore argument.` Root-caused (systematic-debugging) to the replay panel
calling `load_items(bag)` with **no typestore**, while the offline reader path passes
`ROS2_HUMBLE` (`main_window.py` Pitfall 5). Real `rosbag2` sqlite3 bags embed no message
definitions, so `rosbags` cannot deserialize without a typestore. Fixed by exposing the
window's typestore and threading it into the replay loader — desktop-only, no library change.

## What changed

### Commit `23017f4` — test fixture (`tools/make_fixtures.py`)
- `write_ros2_sqlite_bag_defless(dest_dir)`: writes the standard 3-topic sqlite3 bag via
  `_populate`, then `DELETE FROM message_definitions` from the `.db3`. Mirrors
  `write_def_less_bag`'s strip but with **standard** types, so it loads WITH `ROS2_HUMBLE`
  and fails WITHOUT — the exact user condition (verified: `load_items(bag)` → AnyReaderError;
  `load_items(bag, default_typestore=ROS2_HUMBLE)` → 9 items).

### Commit `b504ac6` — the fix + regression tests
- **`main_window.py`**: added `self._default_typestore = None` cache + a public, cached
  `default_typestore` property returning `_ros2_humble_typestore()` (lazy `rosbags` import
  preserved — offline/Qt-free top level held). `_open_reader` now uses `self.default_typestore`
  (one source of truth for offline + live).
- **`replay_panel.py`**: added `_default_typestore()` (`getattr(self.window(),
  "default_typestore", None)` — same channel as `_bag_path` / `_ros_available`) and passed
  `default_typestore=self._default_typestore()` into BOTH `load_items` calls
  (`_ensure_transport` line ~258, `_load_markers` line ~470).
- **`tests/test_desktop.py`**: two headless regression tests —
  (A) `test_window_typestore_resolves_defless_sqlite_bag`: `load_items(bag)` raises on the
  def-less fixture, `window.default_typestore` is non-None, and feeding it to `load_items`
  loads the bag.
  (B) `test_replay_panel_threads_typestore_into_load_items`: drives the rclpy-free
  `_load_markers` path, stubs `list_events` to a 1-row sidecar, spies `load_items`, and
  asserts the panel forwarded `default_typestore is window.default_typestore`.
