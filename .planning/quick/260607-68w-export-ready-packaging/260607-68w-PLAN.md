# Quick Task 260607-68w: Make rosbagger export-ready as a package

## Goal

Make the repo cleanly distributable as a Python package set: every package
PyPI-publishable, a simple README with a one-line install, a one-command
bootstrap installer, and a documented publish path. **Do not** convert to a
colcon/ament ROS package (would break the zero-ROS offline guarantee). **Do
not** push to GitHub (user handles that later).

## Context (from repo audit)

- 7 hatchling packages under `packages/*`, version 0.2.0, src-layout, uv workspace.
- Each `[project]` table has only name/version/deps/scripts — **missing**
  `description`, `readme`, `license`, `authors`, `urls`, `classifiers`, `keywords`.
- Root `LICENSE` is MIT. Per-package wheels carry no license today.
- README says 0.1.0 (drift) and documents only 2 of 7 packages.
- INSTALL.md is strong on the one-transaction rule but omits desktop + rerun.
- The single-transaction install rule (siblings resolve in one `pip` call because
  workspace sources are stripped from wheels) is the key gotcha to surface.

## Tasks (atomic commits)

### Task 1 — PyPI-publishable metadata for all 7 packages
- **Files:** `packages/*/pyproject.toml` (7), new `packages/*/README.md` (7),
  copied `packages/*/LICENSE` (7).
- **Action:** Add `description`, `readme = "README.md"`, license metadata,
  `authors`, `urls`, `keywords`, `classifiers` to each `[project]`. Copy the root
  MIT LICENSE into each package dir. Write a concise per-package README.
- **Verify:** `uv build` succeeds for rosbagger-core (license-form probe first),
  then all 7; `uvx twine check dist/*` passes. `uv run bagq --version` still works.
- **Done:** all 7 build clean with valid metadata; twine check passes.

### Task 2 — Simplify README + complete INSTALL matrix + kill version drift
- **Files:** `README.md`, `INSTALL.md`.
- **Action:** Rewrite README simple: headline bagq, one-line install (path-based,
  works today), short package table (all 7 grouped), pointer to `./install.sh` and
  INSTALL.md. Fix every `0.1.0` → `0.2.0`. Add desktop + rerun rows to INSTALL.md.
- **Verify:** `grep -rn "0\.1\.0" README.md` returns nothing stale; INSTALL lists 7.
- **Done:** README is short and accurate; no version drift; INSTALL covers all 7.

### Task 3 — One-command installer + publish guide
- **Files:** new `install.sh` (root), new `PUBLISHING.md` (root).
- **Action:** `install.sh` — POSIX bash, `set -euo pipefail`, creates/uses a venv,
  installs the right package set in ONE transaction (default = offline CLI
  core+bagq; flags `--plot`, `--live`, `--desktop`, `--all`, `--venv DIR`), prints
  next steps. `PUBLISHING.md` — uv-native publish path (`uv build` per package,
  `uvx twine check`, `uv publish`), core-first order, TestPyPI dry run, version bump.
- **Verify:** `bash -n install.sh` (syntax) + shellcheck if available; a dry smoke
  of the default path into a throwaway venv installs and runs `bagq --version`.
- **Done:** installer runs end-to-end for the default offline path; publish doc complete.
