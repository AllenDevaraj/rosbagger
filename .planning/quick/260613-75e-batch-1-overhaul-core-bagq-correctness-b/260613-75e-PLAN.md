# Quick Task 260613-75e — Plan

Batch 1 of the whole-codebase review overhaul. Nine CONFIRMED correctness bugs in
`rosbagger-core` and `bagq` that are self-contained (no GUI threading, no new shared
infrastructure — those land in later batches). Each fix is committed atomically with a
regression test. Local runs: `PYTHONPATH="" uv run pytest <file> -q --no-cov`
(this box sources ROS; a Qt/SIGBUS at teardown is harmless — see memory).

## Tasks

### T1 — newA1: `has_star()` matches `COUNT(*)` and any tree-wide star
- **files:** `packages/rosbagger-core/src/rosbagger_core/backend/resolve.py`, `tests/test_backend_resolve.py`
- **action:** Scope star detection to a *projection* star (a bare `Star`, or a qualified
  `t.*` `Column`, sitting directly in a `Select.expressions` list). Exclude a `Star` nested
  inside a function call (`COUNT(*)`, `array_agg(*)`, …). Identity (`is`) membership, not `==`.
- **verify:** `has_star("SELECT COUNT(*) FROM imu")` is False; `SELECT *` / `SELECT t.*` /
  `SELECT *, x` True; `SELECT vx FROM imu` False.
- **done:** `bagq query "SELECT COUNT(*) FROM image" big.bag` no longer materializes heavy blobs.

### T2 — newA4: schemas built for every topic, not just referenced
- **files:** `packages/rosbagger-core/src/rosbagger_core/backend/query.py`, `tests/test_backend_query.py`
- **action:** Replace the eager `schemas_by_table` comprehension over ALL topics with a
  memoized `_schema_for(table)` that builds a topic's schema only when referenced (alias gate
  + load loop). An unbuildable, unreferenced topic must never be constructed.
- **verify:** query against `/imu` succeeds on a bag that also contains a vendor topic whose
  msgtype is absent from the typestore (would raise if its schema were built).
- **done:** one bad/unbuildable topic no longer crashes unrelated queries.

### T3 — newA5: case-sensitive table→topic resolution
- **files:** `packages/rosbagger-core/src/rosbagger_core/backend/query.py`, `tests/test_backend_query.py`
- **action:** Resolve table names case-insensitively (DuckDB/SQL identifiers are
  case-insensitive). Add a `.lower()` fallback map; resolve via topic, dedupe referenced
  topics. Apply to the alias base-topic gate and the Step-6 resolution loop.
- **verify:** a bag with topic `/Imu` → `SELECT t FROM imu` returns rows (today: UnknownTableError).
- **done:** unquoted lowercase references to capitalized topics resolve.

### T4 — newA6: `-o` extension validated post-query, raw ValueError
- **files:** `packages/bagq/src/bagq/cli.py`, `tests/test_cli_query.py`
- **action:** Preflight the `-o` extension BEFORE opening the reader / running the query;
  raise `typer.BadParameter` (clean message, no traceback) for anything but `.csv`/`.parquet`
  — mirroring the existing `--format` guards. Keep export.py's ValueError as core defense.
- **verify:** `bagq query "SELECT 1" bag -o out.txt` exits non-zero with a clean message and
  does NOT run the query (no traceback).
- **done:** bad output extension fails fast and cleanly.

### T5 — newA7: TF `.transforms` AttributeError on wrong msgtype
- **files:** `packages/rosbagger-core/src/rosbagger_core/tf.py`, `packages/rosbagger-core/src/rosbagger_core/errors.py`, `packages/bagq/src/bagq/cli.py`, `tests/test_tf.py`
- **action:** Add a msgtype guard: if a present `/tf` or `/tf_static` carries a msgtype other
  than `tf2_msgs/msg/TFMessage`, raise a new `NonTfMessageError` (teaching) BEFORE the stream
  walk. Add it to bagq's `teaching_errors` tuple.
- **verify:** a bag whose `/tf` carries `std_msgs/msg/String` raises `NonTfMessageError`, not
  `AttributeError`.
- **done:** wrong-typed TF topic teaches instead of dumping a traceback.

### T6 — newA8: TF reads start/end without the empty-bag sentinel guard
- **files:** `packages/rosbagger-core/src/rosbagger_core/tf.py`, `tests/test_tf.py`
- **action:** Mirror `inspect.collect_bag_info`: when `reader.message_count == 0`, set
  `start_ns`/`end_ns` to `None` (the AnyReader `2**63-1` / `0` sentinels are ints and slip
  past the `isinstance(int)` check). The CLI render already guards `None` → "—".
- **verify:** an empty TF bag (registered `/tf`, zero messages) yields `start_ns is None` and
  JSON emits `null`, not `9223372036854775807`.
- **done:** empty TF bags no longer emit garbage bounds.

### T7 — newA2: `events add` truncates float seconds
- **files:** `packages/bagq/src/bagq/cli.py`, `tests/test_cli_events.py`
- **action:** `int(start * 1e9)` → `round(start * 1e9)` for both `t_start_ns`/`t_end_ns`
  (the WR-06 fix already in `operations.py:116`).
- **verify:** `--start 4.1 --end 8.2` stores `4_100_000_000` / `8_200_000_000`, not `…999999`.
- **done:** point events land on the exact message they mark.

### T8 — newE22: mixed-msgtype topic silently unqueryable
- **files:** `packages/rosbagger-core/src/rosbagger_core/backend/query.py`, `packages/rosbagger-core/src/rosbagger_core/errors.py`, `packages/bagq/src/bagq/cli.py`, `tests/test_query_errors.py`
- **action:** Record topics skipped for `msgtype is None`; when an unresolved table name
  matches such a topic (by sanitized name, case-insensitive), raise a new `MixedTypeTopicError`
  explaining the topic exists but carries multiple message types. Add to `teaching_errors`.
- **verify:** a topic with two msgtypes across merged bags → `SELECT * FROM status` raises
  `MixedTypeTopicError` naming the topic, not `UnknownTableError` listing only other tables.
- **done:** mixed-type topics get a truthful error.

### T9 — newE23: multi-bag `events` join silently drops other bags' events
- **files:** `packages/rosbagger-core/src/rosbagger_core/backend/query.py`, `packages/rosbagger-core/src/rosbagger_core/errors.py`, `packages/bagq/src/bagq/cli.py`, `tests/test_query_errors.py`
- **action:** When the reserved `events` table is referenced and `len(reader.paths) > 1`,
  raise a new `MultiBagEventsError` (multi-bag events deferred — query each bag individually)
  instead of silently loading only `paths[0]`. Add to `teaching_errors`.
- **verify:** a 2-bag reader + a query joining `events` raises `MultiBagEventsError`.
- **done:** no silently-wrong multi-bag event analysis.
