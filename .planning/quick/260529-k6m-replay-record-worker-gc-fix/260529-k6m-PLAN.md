# Quick Task 260529-k6m: Fix desktop live replay/record drive-worker garbage-collection

## Problem

Desktop **Replay → Play** reported `Playing…` but published **zero** messages — the
scrubber playhead never advanced and nothing reached the live ROS graph / RViz.

Root cause: `ReplayPanel._start_drive()` did `self._drive_thread, _ = run_on_thread(...)`,
keeping the `QThread` but discarding the `BlockingWorker` into `_`. The worker is a
parentless `QObject`; with no surviving Python reference it was garbage-collected before
the queued `thread.started → worker.run` connection fired, so `Replayer.run()` never
executed. The thread reported `isRunning() == True` but ran an empty shell.

`RecordPanel` had the **identical slip** at two sites (`_scan_topics`, `_start_record`),
so live topic discovery and recording were broken the same way. The inspect/query/tf
panels already keep `self._*_worker` and were unaffected — they are the reference pattern.

Found while debugging a user report ("started rviz2, pressed Play, nothing shows up") on a
real rosbag2 sqlite3 bag. Confirmed by A/B reproduction: dropping the worker ref → 0
published; keeping it → publishes (439 msgs, playhead advances). Continues the same panel's
prior fix `260528-3w6` (typestore threading).

## Tasks

1. **replay_panel.py** — add `self._drive_worker: BlockingWorker | None`; assign it from
   `run_on_thread` (`self._drive_thread, self._drive_worker = ...`); clear it in
   `_on_drive_finished` (mirrors the kept `_drive_thread`).
2. **record_panel.py** — add `self._discover_worker` + `self._record_worker`; assign from
   both `run_on_thread` sites; clear in `_clear_discover_thread` / `_on_record_finished`.
3. **tests/test_desktop_live.py** — make `test_replay_panel_publishes_external_subscriber_receives`
   actually exercise Play: trigger via `play_button.click()` (programmatic, needs no
   visibility) instead of `qtbot.mouseClick` on a non-visible widget (silently dropped — how
   this slipped past the suite, alongside the CI/`PYTHONPATH=""` ROS skip). Now a true
   regression: times out pre-fix, passes post-fix.
