# Quick Task 260530-ja4: Route the spawned Rerun viewer onto the NVIDIA dGPU

## Problem
Rerun's viewer renders with Vulkan (wgpu); on an Optimus laptop it falls back to the iGPU or
software (llvmpipe) unless PRIME-offload env is set. The user otherwise has to prefix every
launch. GLX vars (`__GLX_VENDOR_LIBRARY_NAME`) don't help — Vulkan ignores them.

## Tasks
1. `rosbagger_rerun/session.py`:
   - `_nvidia_vulkan_present()` — True iff an NVIDIA Vulkan ICD exists
     (`/usr/share/vulkan/icd.d/nvidia_icd.json` or `/etc/vulkan/icd.d/nvidia_icd.json`).
   - `_prefer_gpu(env=None)` — when NVIDIA present, `setdefault` the PRIME-offload env
     (`__NV_PRIME_RENDER_OFFLOAD=1`, `__VK_LAYER_NV_optimus=NVIDIA_only`,
     `__GLX_VENDOR_LIBRARY_NAME=nvidia`, `WGPU_POWER_PREF=high`); `env` defaults to `os.environ`.
   - `open_viewer()` calls `_prefer_gpu()` ONLY in spawn mode (before `rec.spawn()`); save mode
     untouched. `setdefault` respects a user's own exports. No-op on non-NVIDIA/non-Linux.
2. `tests/test_rerun_unit.py` — offline tests with a passed-in env dict: injected when
   `_nvidia_vulkan_present` monkeypatched True, no-op when False, setdefault respects pre-set key.

## Verification
