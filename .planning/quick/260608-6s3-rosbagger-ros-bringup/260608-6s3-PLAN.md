# Quick Task 260608-6s3: rosbagger_ros ROS 2 bringup package

## Goal

`ros2 launch rosbagger_ros desktop.launch.py [bag:=/path]` opens the existing
rosbagger-desktop GUI inside a sourced ROS env. Thin ament_python package under
`ros/` (outside the uv workspace). The 7 pip packages stay untouched / offline.

## Tasks (atomic commits)

### Task 1 — Scaffold the ament_python package + launch file + README
- **Files (new):** `ros/rosbagger_ros/{package.xml,setup.py,setup.cfg,resource/rosbagger_ros,rosbagger_ros/__init__.py,launch/desktop.launch.py,README.md}`; append colcon artifacts to root `.gitignore`.
- **Action:** Standard ament_python skeleton (no pyproject.toml). `desktop.launch.py`:
  DeclareLaunchArgument `bag` (default ''), OpaqueFunction builds
  `['rosbagger-desktop'] + ([bag] if bag else [])`, ExecuteProcess(output='screen'),
  RegisterEventHandler(OnProcessExit → EmitEvent(Shutdown())). README documents the
  two install recipes + `bag:=` usage.
- **Verify:** `python3 -c "compile(open('ros/rosbagger_ros/launch/desktop.launch.py').read(), 'desktop.launch.py', 'exec')"` exits 0 (no ROS needed).
- **Done:** files exist; launch file compiles.

### Task 2 — Verify it builds + launches under ROS, and the 7 packages are untouched
- **Action (verification only):**
  1. Offline invariant intact: `PYTHONPATH="" uv sync --locked` + `PYTHONPATH="" uv run pytest tests/test_offline_guard.py` pass; `uv build packages/rosbagger-core` still works (new dir invisible to uv).
  2. ROS build in a TEMP workspace (keep repo clean): symlink `ros/rosbagger_ros` into `/tmp/rbq_ros_ws/src/`, `colcon build --packages-select rosbagger_ros`, `source install/setup.bash`, `ros2 launch rosbagger_ros desktop.launch.py --show-args` → shows `bag` arg, exits 0.
- **Done:** colcon build succeeds; --show-args lists `bag`; offline guard + uv unaffected.

## Out of scope
- Node-wrapping record/replay; ament-ifying the 7 packages; a TUI launch file;
  publishing the bringup package. Per spec non-goals.

- `ros/rosbagger_ros/` is a valid ament_python package with `desktop.launch.py`.
- No `pyproject.toml` under `ros/` (uv stays blind to it); `uv sync --locked` + offline guard still green.
- `colcon build --packages-select rosbagger_ros` succeeds; `ros2 launch ... --show-args` shows `bag` and exits 0.
