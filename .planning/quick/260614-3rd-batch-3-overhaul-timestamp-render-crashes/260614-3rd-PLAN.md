# Quick Task 260614-3rd — Plan

Querying any time column (the canonical `SELECT * FROM imu`) crashed both GUIs: `.as_py()` /
`to_pylist()` on a sub-µs `timestamp[ns]` scalar raises `ValueError` (no pandas, not a GUI dep).

## Tasks
- **SW1** desktop `_ResultTableModel.data()`: render `timestamp[ns]` cells via `numpy.datetime64`
  from the scalar's raw `.value`; precompute temporal columns once; keep the lazy per-cell model.
- **SW2** TUI `_fill_results`: render via core `rows_for_display` (temporal-safe) instead of `to_pylist()`.
- **F6** (row cap): `rows_for_display(max_rows=1000)`; status notes truncation; export writes all rows.
  (The TUI query worker-thread move — F6's sync-on-event-loop half — folds into the GUI-threading batch.)
