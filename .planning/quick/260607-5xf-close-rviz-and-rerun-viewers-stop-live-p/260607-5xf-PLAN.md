# Quick 260607-5xf — Close RViz/Rerun + tear down live panels on GUI close

**Problem (user report):** Closing the GUI (incl. via the overlay ✕) does not close the spawned RViz
viewer — it stays open. Same latent bug for the Rerun viewer.

**Root cause (confirmed headlessly):** Qt does NOT deliver `closeEvent` to CHILD widgets. The live
panels' `ReplayPanel.closeEvent` (which calls `_close_rviz` + `_close_rerun`, stops the drive/record
worker threads, and tears down the rclpy transport) never runs on a `MainWindow` close. The viewers
were left to the `atexit` backstop, which does NOT fire on the known Qt-teardown SIGBUS → orphaned
rviz2/rerun. Verified: `window.close()` did not fire the panel teardown; `replay_panel.close()` does.

**Fix:** `MainWindow.closeEvent` explicitly `close()`es the live panels (`replay_panel`, `record_panel`)
before closing the shared reader, so each panel's `closeEvent` teardown runs during the controlled
close (closing RViz + Rerun + stopping threads) — independent of the unreliable `atexit`.
