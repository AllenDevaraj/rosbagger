<objective>
The Inspect and TF GUI panels render blank in rosbagger-gui: their populated DataTables
are invisible because the panels lay out at height 0.

Purpose: `InspectPanel` and `TfPanel` extend bare `textual.widget.Widget` with NO height
rule anywhere (no `DEFAULT_CSS`, nothing in `app.tcss`), so Textual gives them `height: 0`.
The `QueryPanel` renders correctly only because it extends `Vertical`, which flexes inside
the `Horizontal { height: 1fr }` shell. Data IS reaching the tables (`#bag-info` has 3 rows
at launch) — it is purely a layout collapse. The current SC3 test only asserts `row_count`,
never rendered height, which is why this shipped.

Fix is layout/CSS ONLY — no panel logic changes. Add fill-height rules to `app.tcss` for the
two panels (and sensible heights for their stacked DataTables), then add a regression
assertion proving the panels render with non-zero height.

Output: corrected `app.tcss` + a height regression test in `tests/test_gui.py`.
</objective>
